Install rtl_tcp on Linux

Shown for Debian and Ubuntu; on another distribution use its own package manager in place of apt.

  1. Install the tools 
    sudo apt update
sudo apt install rtl-sdr

    Fedora: sudo dnf install rtl-sdr. Arch: sudo pacman -S rtl-sdr.

  2. Blacklist the kernel's TV driver

    The kernel claims the receiver as a digital TV tuner first, so that driver has to be kept away:

    echo 'blacklist dvb_usb_rtl28xxu' | sudo tee /etc/modprobe.d/blacklist-rtl-sdr.conf
sudo modprobe -r dvb_usb_rtl28xxu

    Then unplug the receiver and plug it back in. (Recent rtl-sdr packages usually do this for you; doing it again does no harm.)

  3. Check the receiver is seen 
    rtl_test -t

    Found 1 device(s) and the model name mean it is working.

    usb_open error -3 means your user may not open the USB device. Add yourself to the plugdev group and log in again: sudo usermod -aG plugdev $USER.

  4. Run rtl_tcp 
    rtl_tcp -a 0.0.0.0

    listening... means it is waiting for the phone. -a 0.0.0.0 lets other devices connect and cannot be left out.

    With a firewall on, open port 1234, for example sudo ufw allow 1234/tcp.

  5. Find this computer's address 
    hostname -I

    The first address printed, something like 192.168.1.20, is the one for the app.

The computer is ready. Next: Connect in the app →

An RTL-SDR Blog V4 or V4L needs a recent driver

These two need librtlsdr 2.0.2 or later (2.0.3 for the V4L). Check with rtl_test -t: it must say RTL-SDR Blog V4 Detected or RTL-SDR Blog V4 Lite Detected. If it shows only an R820T and nothing is received, the packaged version is too old: upgrade the package, or build from source following RTL-SDR Blog's instructions.
