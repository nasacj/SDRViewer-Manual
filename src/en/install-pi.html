Install rtl_tcp on a Raspberry Pi

The least trouble of the four: power it and it runs, no computer left on, and with a power bank it goes to the balcony, the car or the airport fence.

This assumes the Pi already runs Raspberry Pi OS, is on Wi-Fi, and you can log in over SSH or with a screen. If not, write a card with the official Raspberry Pi Imager, which can set the Wi-Fi and turn on SSH as it writes.

  1. Install the tools and check the receiver 
    sudo apt update
sudo apt install rtl-sdr
rtl_test -t

    Found 1 device(s) and the model name mean it is working. For problems see the Linux page; the steps are the same.

  2. Make it a service that starts at boot

    Open an editor on a new service file:

    sudo nano /etc/systemd/system/rtl_tcp.service

    Paste this, then Control + O, Return to save and Control + X to leave:

    [Unit]
Description=rtl_tcp for SDRViewer
After=network-online.target
Wants=network-online.target
StartLimitIntervalSec=0

[Service]
ExecStart=/usr/bin/rtl_tcp -a 0.0.0.0 -p 1234
Restart=always
RestartSec=3
KillSignal=SIGINT
TimeoutStopSec=5
DynamicUser=yes
SupplementaryGroups=plugdev

[Install]
WantedBy=multi-user.target

    Enable it and start it now:

    sudo systemctl daemon-reload
sudo systemctl enable --now rtl_tcp

    Restart=always is what brings it back: if the receiver is unplugged or the program exits, it is tried again every three seconds, so plugging the receiver back in is enough.

  3. Check it is running 
    systemctl status rtl_tcp

    active (running) is what you want. journalctl -fu rtl_tcp shows its output.

  4. Find the Pi's address 
    hostname -I

    Or use its name: a Pi announces its hostname, so raspberrypi.local (or the name you gave it, plus .local) usually works in the app, with no numbers to remember.

The Pi is ready. Next: Connect in the app →

Taking it outdoors

  • Power: a Pi 4 or 5 with one receiver wants a power bank that gives 5 V at 3 A. Short of power, the Pi slows down and the audio stutters.
  • Network: turn on the iPhone's Personal Hotspot and have the Pi join it (set that up at home first). The phone then has the internet and the Pi at once.
  • Two receivers: a Pi can hold two, each with its own rtl_tcp on its own port (1234 and 1236, say). Add one entry for each to the app's receiver list, and you can listen to air traffic while watching ADS-B.
