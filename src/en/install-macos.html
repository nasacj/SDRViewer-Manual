Install rtl_tcp on macOS

About five minutes, and three or four commands in Terminal that you can copy as they are.

  1. Install Homebrew (skip if you have it) Homebrew is the usual way to install command-line software on a Mac. Open Terminal, paste this line, press Return and type your login password when asked: 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    Not sure whether you have it? Type brew --version; a version number means you do.
  2. Install the RTL-SDR tools 
    brew install librtlsdr
    This installs rtl_tcp, rtl_test and a few others.
  3. Plug in the receiver and check it is seen 
    rtl_test -t
    Output like this means it is working (the wording differs by model): 
    Found 1 device(s):
  0:  RTLSDRBlog, Blog V4L, SN: 00000001
Found Rafael Micro R820T tuner

    If it says No supported devices found, try another USB port, or take a USB hub out of the way.

  4. Run rtl_tcp 
    rtl_tcp -a 0.0.0.0
    listening... means it is waiting for the phone. Leave this Terminal window open: closing it stops the server. Press Control + C to stop it.

    -a 0.0.0.0 means "let other devices connect". Without it only this Mac can, and the phone cannot.

    If macOS asks whether to accept incoming network connections, choose Allow.
  5. Find this Mac's address In a second Terminal window: 
    ipconfig getifaddr en0
    It prints an address like 192.168.1.20. Note it down for the app. (On a wired Mac with no output, try en1; or look in System Settings → Network.)

The computer is ready. Next: Connect in the app →

Common questions

An RTL-SDR Blog V4 or V4L receives nothing

These two need a recent driver. Run brew upgrade librtlsdr, then rtl_test -t, which should say RTL-SDR Blog V4 Detected or RTL-SDR Blog V4 Lite Detected.

usb_claim_interface error

Another program is holding the receiver, usually an rtl_tcp already running or another SDR application. Close it and try again.

Starting it automatically

The simplest way is to save the command above as a script and add it to System Settings → General → Login Items. For everyday use a Raspberry Pi is the better home for it: the computer need not stay on.
