YSF 数字语音（System Fusion）

System Fusion（简称 YSF 或 C4FM）是八重洲（Yaesu）电台的数字语音制式。SDRViewer 接收它的方式和 D-STAR 完全一样：同一个 Digital 方式、同一张卡片、同一个 RX History。能听到语音，看到对方的呼号、电台 ID 和位置。目前支持 DN 和 VW 两种语音格式。

怎么开始收

  1. 调到 YSF 的频率在 Receiver 页面输入频率，比如本地的 C4FM 直频或 YSF 中继的下行频率。
  2. 解调方式选 Digital点左边蓝色的方式按钮，选 Digital。D-STAR 和 YSF 不用分开选：两种信号各带校验，App 自己认出是哪一种。选 NFM 也一样：来了数字信号按钮会自动变成 Digital，来了模拟调频就变回 NFM 播出来，和八重洲车台的 AMS 一样。
  3. 点播放，等人发射有人发射时，页面下方弹出卡片，扬声器里播放解码后的语音。

频率要准。和 D-STAR 一样，接收机频率偏了就解不出来。使用前先完成频率校准；手持机离接收机太近（几米之内）信号过强也会解不出来。

收语音时弹出的卡片

卡片上的内容

第一行：对方的呼号。左边的绿点和右上角的 RX 表示正在接收。

→ CQCQCQ：对方呼叫的对象。全是星号表示呼叫所有人；以 ID 开头时，对方用的是电台 ID 呼叫。

YSF DN · ID F0DM2：发送格式和对方电台的 5 位 ID。DN 是语音和数据各占一半的格式，八重洲电台默认用它；VW 是全速语音，音质更好但不带数据。对方设了 DG-ID 时，这一行也会显示。

位置（对方电台开了 GPS 才有）：HUP / NUP 是罗盘现在的朝向方式（见下）；DISTANCE 是对方到你的距离；下面是对方的经纬度和网格（GL），以及对方自己的航向和速度（COURSE / SPEED）。

罗盘：HUP 和 NUP

罗盘照八重洲电台的导航画面画：蓝色小人标出对方所在的方向，红色箭头是你自己。

方式样子什么时候
HUP（Heading up，朝向朝上）红箭头永远朝上，代表你手机指的方向；N/E/S/W 和蓝色小人跟着手机转动。手机转到让蓝色小人在正上方，你就正对着对方。手机有指南针，并且设置里“我的位置”打开了表盘随手机朝向转和跟随我的位置。
NUP（North up，正北朝上）N 固定在上方，表盘不转；不画红箭头。没有指南针（Mac、部分 iPad），或者关掉了表盘随手机朝向转。

距离和方向是按你的位置算的。在设置的“我的位置”里填上坐标或网格，或者打开“跟随我的位置”。没填的话卡片只显示对方的坐标，不显示罗盘和距离，因为瞎猜一个位置算出来的距离是错的。

对方没发位置时

对方电台没开 GPS，或者还没定到位，卡片就只有呼号、呼叫对象和发送格式三行，没有罗盘。语音照常播放。

没有呼号时

呼号所在的数据没通过校验（通常是信号太弱）时，发射期间不弹卡片，但语音仍然照常解码播放。发射结束后，这次通联以（无呼号）存进 RX History，可以回放。

RX History：收到过的通联

点 Receiver 页面右上角的时钟图标打开。YSF 和 D-STAR 的记录在同一个列表里，左边的标签写着 YSF 或 DSTAR，最新的在最上面。

列表上的标记和 D-STAR 一样：喇叭图标和秒数表示有语音，塔形图标后面是对方的距离和方向。点一条记录看详情；向左滑删除单条；右上角的垃圾桶清空全部。

带位置的记录

顶部是播放按钮，点一下回放当时的语音。下面和 D-STAR 的记录一样分成通联、对方、位置、信号几张卡片；通联卡片的模式格写着 YSF，下面小字是 DN 或 VW。YSF 自己的几项：

字段含义
发送格式DN 或 VW；对方用窄带时后面写“窄带”。
电台 ID对方电台自己的 5 位 ID，每台八重洲电台出厂就有。
DG-ID对方设了 DG-ID（数字群组号）时才有。
上行 / 下行经过中继或 WIRES-X 节点时，信号进入和发出的中继。
位置和卡片一样的罗盘、距离、坐标、航向和速度；“发送格式”一行写着 YSF DT，即位置来自数据帧里的 GPS。
语音语音帧数、长度和声码器纠正的错误位数，越少说明信号越干净。

没有呼号的记录

只剩模式、频率、时间、时长、发送格式和语音几行，语音照样可以回放。

常见情况

现象原因和办法
瀑布图上有信号，但没有卡片也没有声音频率偏了，先做频率校准；或者信号太强，离发射机远一点；也可能那不是 YSF 或 D-STAR 信号。
有声音但没有卡片呼号没收到，见上面“没有呼号时”。
卡片上没有罗盘对方没开 GPS，或者你没有填自己的位置。
罗盘一直是 NUP设备没有指南针，或者设置里没打开“表盘随手机朝向转”。
收不到 DW 模式DW（数据全速）不带语音，目前不解码。
