航图数据文件

ATC 页面里的机场频率，ADS-B 页面上的航路、导航台和进离场程序，都来自一个你自己导入的 JSON 文件。App 本身不带任何国家的航图数据。这一页说明这个文件长什么样，并给出一份可以直接下载试用的洛杉矶示例。

先试一下示例

  1. 下载示例文件atc-lax.json（约 600 KB）：洛杉矶国际机场周边 90 公里内的 20 个有塔台的机场、152 个频率、51 个导航台、84 条航路和 698 条进离场程序。数据整理自美国联邦航空局（FAA）公开发布的 NASR 数据，生效日期 2026-10-29。
  2. 把文件放到 iPhone 上用隔空投送、iCloud 云盘或者“文件”App，任何能让 iPhone 看到这个文件的方式都可以。
  3. 在 App 里导入打开 ATC 页面。第一次使用时页面上有一个“选择文件”按钮，点它，在文件列表里选中刚才的 JSON。也可以在“文件”App 里长按这个文件，选“共享”，再选 SDRViewer。
  4. 去 ADS-B 页面看效果把地图或雷达移到洛杉矶，就能看到上面截图里的画面。右上角的图层按钮可以分别开关航路、航路点、导航台、机场和各类程序。

不可用于导航。这些数据只是接收机屏幕上的背景图，会过期，也可能有错。任何飞行用途请使用官方发布的现行资料。

为什么要自己导入

各国的航行资料由各自的民航部门发布，版权和使用条件各不相同：有的国家（如美国）公开且可以自由使用；有的国家可以免费查阅，但不允许再分发。所以 App 不内置数据，而是规定一种文件格式，由你把自己有权使用的数据放进来。

文件的整体结构

文件是一个 JSON 对象，开头是几项说明，后面是五个列表。哪个列表都可以是空的 []：只有机场频率也能用。

{
  "format": "sdrviewer-atc",
  "version": 1,
  "region": "us-klax",
  "updated": "2026-10-29",
  "source": "FAA NASR 28-day subscription, effective 2026-10-29 …",
  "airports":   [ … ],
  "navaids":    [ … ],
  "routes":     [ … ],
  "procedures": [ … ],
  "sectors":    [ … ]
}
字段含义
format固定写 "sdrviewer-atc"，App 靠它认出这是航图数据文件。
version格式版本，目前是 1。
region你给这份数据起的简称，随意。
updated数据的日期。航行资料每 28 天更新一次，写上日期才知道它有多旧。
source数据来源的说明，会显示在 App 里。

所有坐标都是十进制度，WGS-84：北纬和东经为正，南纬和西经为负。洛杉矶的经度是 -118.408。频率的单位是 MHz。

airports：机场和频率

每个机场一项，里面的 channels 是这个机场的各个频率。ATC 页面按它列出可以收听的频率，ADS-B 页面用它画机场的圆圈和名字。

{
  "icao": "KLAX",
  "iata": "LAX",
  "name": "Los Angeles Intl",
  "nameEnglish": "Los Angeles Intl",
  "position": {"lat": 33.9425, "lon": -118.40805, "elevationMetres": 39.0},
  "channels": [
    {"role": "atis", "label": "ATIS · Arr", "mhz": 133.8, "callsignEnglish": "Los Angeles ATIS", "hours": "H24"},
    {"role": "delivery", "label": "Clearance", "mhz": 120.35, "callsignEnglish": "Los Angeles Clearance", "hours": "H24"},
    {"role": "ground", "label": "Ground · South Cmplx", "mhz": 121.75, "callsignEnglish": "Los Angeles Ground", "hours": "H24"},
    {"role": "tower", "label": "Tower · North Cmplx", "mhz": 133.9, "callsignEnglish": "Los Angeles Tower", "hours": "H24"}
  ]
}
字段必填含义
icao是机场的四字代码，是它的唯一标识，程序和扇区都用它来指向机场。
iata三字代码，只用于显示。
name / nameEnglish是当地语言的名称和英文名称。只有一种时两个写成一样。
position是机场基准点的纬度、经度和标高（米）。
channels[].role是这个频率是干什么的，见下表。
channels[].mhz是频率。
channels[].label显示在按钮上的短名称，比如扇区名或“北跑道”。
channels[].callsign / callsignEnglish无线电呼号，如“Los Angeles Tower”。
channels[].backup备用频率。
channels[].hours开放时间，H24 表示全天。
channels[].note任何补充说明。

role 可以用的值：

role含义
atis通播（机场情报自动广播）。一直在播，最适合用来测试接收。
delivery放行许可
ground地面管制
apron机坪管制
tower塔台
approach进近和离场
emergency应急频率 121.5
ops航空公司或机场运行频率

写了不认识的 role 不会导致整个文件被拒绝，那一项会归到“其它”。

navaids：导航台

地面的无线电导航台（VOR、NDB）。ADS-B 页面把它们画成航图上的符号，放大后在 VOR 周围画出方位刻度盘。

{"ident": "LAX", "type": "VOR/DME", "name": "Los Angeles", "lat": 33.93315, "lon": -118.43201, "frequency": "113.6 MHz"}
字段必填含义
ident是导航台的识别码，两到三个字母。
type是VOR/DME 或 NDB，决定画哪种符号。
lat / lon是位置。
frequency频率，带单位的文字，如 "113.6 MHz" 或 "362 kHz"。
name / nameChinese名称。

routes：航路

一条航路是一串按顺序排列的点。ADS-B 页面把相邻的点连成线，并在线上标出航路代号。

{
  "designator": "V23",
  "section": "NASR AWY",
  "points": [
    {"name": "OCN", "lat": 33.24063, "lon": -117.41772, "compulsory": false},
    {"name": "KELPS", "lat": 33.3242, "lon": -117.51505, "compulsory": false},
    {"name": "DANAH", "lat": 33.48101, "lon": -117.69837, "compulsory": false},
    {"name": "SLI", "lat": 33.7833, "lon": -118.05476, "compulsory": false}
  ]
}
字段必填含义
designator是航路代号，如 V23、J5、A593。
points[].name是航路点或导航台的名字。
points[].lat / lon是这个点的位置。每个点都自带坐标，不需要另外的航路点表。
points[].compulsory是否为强制报告点，影响符号是实心还是空心。
section数据出处的章节，只作备注。

航路很长时不必给全：示例只保留了每条航路进入洛杉矶周边 280 公里的那一段。

procedures：进离场和进近程序

一条程序是从一个点飞到另一个点的一串航段。ADS-B 页面按类型用不同颜色画出来，并沿线画箭头表示飞行方向。

{
  "kind": "sid",
  "name": "ORCKA5",
  "airport": "KLAX",
  "runways": ["24L"],
  "byATC": false,
  "legs": [
    {"type": "DER", "fix": "", "lat": 33.94682, "lon": -118.43467},
    {"type": "TF", "fix": "DLREY", "lat": 33.94368, "lon": -118.46515},
    {"type": "TF", "fix": "KLIPR", "lat": 33.92951, "lon": -118.43878},
    {"type": "TF", "fix": "KEGGS", "lat": 34.00845, "lon": -118.29959},
    {"type": "TF", "fix": "COOPP", "lat": 34.12113, "lon": -118.10053},
    {"type": "TF", "fix": "ORCKA", "lat": 34.34973, "lon": -117.69314}
  ]
}
字段必填含义
kind是sid 离场，star 进场，approach 进近，missed 复飞，hold 等待。
name是程序名，如 ORCKA5。
airport是所属机场的四字代码，要和 airports 里的一致。
runways是适用的跑道，可以是空列表。在 App 里选定跑道方向后，只显示对应跑道的程序。
transition过渡段的名字。同一条程序常常分成“主体”和若干条通向不同方向的过渡段，各写成一项。
byATC是否为“由管制员指定”的程序。
legs是航段列表，至少两个带坐标的点才画得出来。

每个航段的字段：

字段含义
type航段类型，见下表。不确定时，第一个点写 IF，后面都写 TF 即可。
fix这个航段终点的航路点名字，没有名字时写空字符串。
lat / lon终点的位置。
altitude高度限制，文字形式："1200" 表示正好，"≥1500" 不低于，"≤1800" 不高于，"≤1800/≥1200" 在两者之间。放大后显示在航路点旁边。
speed速度限制，如 "MAX250"。
course航向（度）。
turn转弯方向，"L" 或 "R"。
flyOver是否必须飞越这个点。
type含义
IF起始点
TF从上一个点直线飞到这个点。最常用。
DF从当前位置直飞这个点
CF沿指定航向飞到这个点
DER跑道离场端，离场程序的起点
VA / CA保持航向爬升到指定高度（没有固定的终点）
HM等待航线，配合 course 和 turn

洛杉矶示例整理自 FAA 的 NASR 数据，那里面只有程序经过哪些点，没有高度和速度限制，也没有进近程序。所以示例里的程序只有线和点名；上面表里的 altitude、speed 等字段在你自己的数据里有就可以写。

sectors：管制扇区

一个扇区是一块有高度范围的空域，归一个管制席位管，有自己的频率。ATC 页面用它回答“我现在所在的位置归谁管、该听哪个频率”；ADS-B 页面把扇区边界画出来。

洛杉矶示例里没有扇区（sectors 是空的），因为 FAA 的这份数据不含扇区的形状。下面是一个编造的进近扇区，用来说明格式：

{
  "id": "ZZZZAP01",
  "name": "AP01",
  "kind": "approach",
  "callsignEnglish": "Example Approach",
  "mhz": 119.3,
  "backup": 124.5,
  "hours": "H24",
  "serves": ["ZZZZ"],
  "volumes": [
    {
      "ring": [[30.98925, -140.0], [30.9492, -141.1122], [29.99507, -141.14225], [29.04163, -141.09102], [29.01075, -140.0]],
      "lower": {"metres": 0, "surface": true},
      "upper": {"metres": 6000, "datum": "STD"}
    }
  ]
}
字段必填含义
id是扇区的唯一标识。
name是扇区名。
kind是area 区域管制，approach 进近，terminal 终端区。图层菜单按这个分类开关。
mhz是主频率。
callsign / callsignEnglish无线电呼号。
backup、hours备用频率、开放时间。
serves这个扇区服务的机场代码列表。
volumes是一块或几块空域。每块有边界 ring 和上下限。
volumes[].ring是边界的顶点，按顺序排列的 [纬度, 经度]，首尾不用重复。
volumes[].lower / upper是下限和上限，单位米。"surface": true 表示从地面起；"datum": "STD" 表示按标准气压（飞行高度层）。

自己做一份

你想要的怎么做
只要几个机场的频率下载上面的示例，照着改 airports 一节，其它列表留空。手写就够了。
一个国家或地区的完整数据从该国民航部门发布的航行资料（AIP）里整理。请先确认它的使用条款：很多国家的资料可以免费查阅，但不允许再分发，这种情况下做出来的文件只能自己用。

导入时出错

现象原因和办法
提示文件无法读取不是合法的 JSON。最常见的是多了或少了逗号、引号没配对。用任何一个 JSON 校验工具检查一下。
导入成功，但 ADS-B 上什么都没画画面不在数据覆盖的地区（把地图移过去），或者图层菜单顶上的 Chart 总开关关着。
程序画出来了，但位置明显不对经纬度写反了，或者西经、南纬忘了写负号。
地图刚打开时有几秒“Loading chart…”正常。文件越大这一步越久，全国范围的数据需要几秒。
ATC 页面显示“已发布空域之外”文件里没有覆盖你当前位置的扇区。只有机场频率、没有扇区的文件就是这样，频率仍然可以在机场列表里找到。
