在树莓派上安装 rtl_tcp

树莓派是最省心的方案：插上电自动运行，不用开电脑，配一个充电宝还能带到阳台、车里或者机场边。

下面假设树莓派已经装好 Raspberry Pi OS、连上了 Wi-Fi，并且你能通过 SSH 或者接显示器登录它。还没装系统的话，用官方的 Raspberry Pi Imager 烧一张卡，烧录时可以顺便填好 Wi-Fi 和开启 SSH。

  1. 安装工具并检查接收机 
    sudo apt update
sudo apt install rtl-sdr
rtl_test -t

    看到 Found 1 device(s) 和型号就对了。遇到问题参考 Linux 一篇，步骤完全相同。

  2. 做成开机自动运行的服务

    把下面的内容保存成一个服务文件。先打开编辑器：

    sudo nano /etc/systemd/system/rtl_tcp.service

    粘贴以下内容，然后按 Control + O 回车保存，Control + X 退出：

    [Unit]
Description=rtl_tcp for SDRViewer
After=network-online.target
Wants=network-online.target
StartLimitIntervalSec=0

[Service]
ExecStart=/usr/bin/rtl_tcp -a 0.0.0.0 -p 1234
Restart=always
RestartSec=3
KillSignal=SIGINT
TimeoutStopSec=5
DynamicUser=yes
SupplementaryGroups=plugdev

[Install]
WantedBy=multi-user.target

    启用并立即启动：

    sudo systemctl daemon-reload
sudo systemctl enable --now rtl_tcp

    Restart=always 的作用是：接收机被拔掉或者程序出错退出后，每 3 秒自动重试，重新插上就能恢复。

  3. 确认它在运行 
    systemctl status rtl_tcp

    看到 active (running) 就好了。想看它的输出用 journalctl -fu rtl_tcp。

  4. 查到树莓派的地址 
    hostname -I

    也可以直接用名字：树莓派默认会广播自己的主机名，在 App 里填 raspberrypi.local（或者你给它起的名字加 .local）通常就能连上，不用记数字地址。

带出门用

  • 供电：树莓派 4 / 5 加一只接收机，用能输出 5V 3A 的充电宝。电不够时树莓派会降频，表现为声音卡顿。
  • 网络：打开 iPhone 的个人热点，让树莓派连这个热点（提前在家里配置好）。这样手机既能上网，又能连到树莓派。
  • 两只接收机：树莓派可以同时插两只，各运行一个 rtl_tcp，用不同的端口（比如 1234 和 1236）。App 里的接收机列表可以各加一项，这样可以一边听航空通话一边看 ADS-B。
