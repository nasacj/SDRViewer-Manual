在树莓派上安装 rtl_tcp

树莓派是最省心的方案：插上电自动运行，不用开电脑，配一个充电宝还能带到阳台、车里或者机场边。

下面假设树莓派已经装好 Raspberry Pi OS、连上了 Wi-Fi，并且你能通过 SSH 或者接显示器登录它。还没装系统的话，用官方的 Raspberry Pi Imager 烧一张卡，烧录时可以顺便填好 Wi-Fi 和开启 SSH。

  1. 安装工具并检查接收机 
    sudo apt update
sudo apt install rtl-sdr
rtl_test -t

    看到 Found 1 device(s) 和型号就对了。遇到问题参考 Linux 一篇，步骤完全相同。

    用的是 RTL-SDR Blog V4 或 V4L？先看下面的新版驱动一节，系统自带的版本很可能认不出它。

  2. 做成开机自动运行的服务

    把下面的内容保存成一个服务文件。先打开编辑器：

    sudo nano /etc/systemd/system/rtl_tcp.service

    粘贴以下内容，然后按 Control + O 回车保存，Control + X 退出：

    [Unit]
Description=rtl_tcp for SDRViewer
After=network-online.target
Wants=network-online.target
StartLimitIntervalSec=0

[Service]
ExecStart=/usr/bin/rtl_tcp -a 0.0.0.0 -p 1234
Restart=always
RestartSec=3
KillSignal=SIGINT
TimeoutStopSec=5
DynamicUser=yes
SupplementaryGroups=plugdev

[Install]
WantedBy=multi-user.target

    启用并立即启动：

    sudo systemctl daemon-reload
sudo systemctl enable --now rtl_tcp

    Restart=always 的作用是：接收机被拔掉或者程序出错退出后，每 3 秒自动重试，重新插上就能恢复。

  3. 确认它在运行 
    systemctl status rtl_tcp

    看到 active (running) 就好了。想看它的输出用 journalctl -fu rtl_tcp。

  4. 查到树莓派的地址 
    hostname -I

    也可以直接用名字：树莓派默认会广播自己的主机名，在 App 里填 raspberrypi.local（或者你给它起的名字加 .local）通常就能连上，不用记数字地址。

树莓派准备好了。接下来：在 App 里连接 →

RTL-SDR Blog V4 / V4L：升级驱动

这两个型号需要较新的驱动（librtlsdr）：V4 要 2.0.2 以上，V4L 要 2.0.3 以上。驱动太旧时，rtl_tcp 照样能启动、App 也能连上，瀑布图在动，但一个信号都收不到，很容易误以为是天线或增益的问题。

先确认是不是这个问题

rtl_test 和 rtl_tcp 不能同时用一只接收机，所以先停掉服务：

sudo systemctl stop rtl_tcp
rtl_test -t

正确识别时会出现 RTL-SDR Blog V4 Detected 或 RTL-SDR Blog V4 Lite Detected。只看到 Found Rafael Micro R820T tuner、后面没有这一行，就是驱动太旧。按 Control + C 退出。

再看系统版本和驱动版本，决定用哪种方法：

grep VERSION_CODENAME /etc/os-release
dpkg -l librtlsdr0 | tail -1
系统自带的驱动怎么办
trixie（2025 年下半年以后的 Raspberry Pi OS）2.0.2：V4 可以，V4L 不行方法一：装 Debian 的 2.0.3 安装包
bookworm 或更早0.6.0：V4、V4L 都不行方法二：从源码编译，或者重新烧一张新系统

方法一：trixie，装 Debian 的 2.0.3 安装包

Debian 新版本里已经有 2.0.3，而且这两个安装包在 trixie 上可以直接装，不用改软件源：

sudo systemctl stop rtl_tcp
cd /tmp
arch=$(dpkg --print-architecture)
wget http://deb.debian.org/debian/pool/main/r/rtl-sdr/librtlsdr0_2.0.3-1_${arch}.deb \
     http://deb.debian.org/debian/pool/main/r/rtl-sdr/rtl-sdr_2.0.3-1_${arch}.deb
sudo apt install ./librtlsdr0_2.0.3-1_${arch}.deb ./rtl-sdr_2.0.3-1_${arch}.deb
rtl_test -t

看到 RTL-SDR Blog V4 Lite Detected 后按 Control + C，再启动服务：

sudo systemctl start rtl_tcp
  • $(dpkg --print-architecture) 会自动填 arm64（64 位系统）或 armhf（32 位系统）。
  • 如果下载报 404，说明 Debian 已经换了更新的版本号：打开 这个目录，找 librtlsdr0_ 和 rtl-sdr_ 开头、2.0.3 或更高、架构对得上的两个文件，把命令里的版本号换掉。
  • 只装这两个包，不要把 Debian 的测试版加进软件源，那样系统会提示把整个系统升级上去。
  • 以后 sudo apt upgrade 不会把它降回旧版；等 trixie 自己带上 2.0.3 或更新版本时，会正常替换。

方法二：bookworm 或更早，从源码编译

Debian 的 2.0.3 安装包需要比 bookworm 更新的系统库，在 bookworm 上装不上。可以按 RTL-SDR Blog 官方的方法从源码编译（树莓派 4 / 5 上大约几分钟）：

sudo systemctl stop rtl_tcp
sudo apt purge ^librtlsdr rtl-sdr
sudo apt install git cmake build-essential pkg-config libusb-1.0-0-dev
git clone https://github.com/rtlsdrblog/rtl-sdr-blog
cd rtl-sdr-blog
mkdir build && cd build
cmake .. -DINSTALL_UDEV_RULES=ON
make
sudo make install
sudo ldconfig
echo 'blacklist dvb_usb_rtl28xxu' | sudo tee /etc/modprobe.d/blacklist-dvb_usb_rtl28xxu.conf

编译版装在 /usr/local/bin，不在 /usr/bin。所以要改一下服务文件，把 ExecStart=/usr/bin/rtl_tcp 改成 ExecStart=/usr/local/bin/rtl_tcp：

sudo sed -i 's|/usr/bin/rtl_tcp|/usr/local/bin/rtl_tcp|' /etc/systemd/system/rtl_tcp.service
sudo systemctl daemon-reload

然后拔下接收机再插上（让新的权限规则生效），检查并启动：

rtl_test -t
sudo systemctl start rtl_tcp

另一个办法是用 Raspberry Pi Imager 重新烧一张最新的系统（已经是 trixie），再用方法一。树莓派如果只用来跑 rtl_tcp，这样反而更省事。

还是不行

  • journalctl -u rtl_tcp 里出现 usb_open error -3：权限规则还没对这只接收机生效，拔下再插上，或者重启树莓派。
  • rtl_test 报设备被占用：服务还在运行，先 sudo systemctl stop rtl_tcp。

带出门用

  • 供电：树莓派 4 / 5 加一只接收机，用能输出 5V 3A 的充电宝。电不够时树莓派会降频，表现为声音卡顿。
  • 网络：打开 iPhone 的个人热点，让树莓派连这个热点（提前在家里配置好）。这样手机既能上网，又能连到树莓派。
  • 两只接收机：树莓派可以同时插两只，各运行一个 rtl_tcp，用不同的端口（比如 1234 和 1236）。App 里的接收机列表可以各加一项，这样可以一边听航空通话一边看 ADS-B。
