BL618 无线小板

不想带电脑，也不想折腾树莓派？一块几十元的开发板就能当 rtl_tcp 服务器：RTL-SDR 插在它上面，它自己开一个 Wi-Fi 热点，手机连上热点就能收。充电宝供电，插上电几秒就能用，放进口袋带到机场、山顶都行。

固件和全部说明在 GitHub 上：nasacj/rtlsdr-iphone-bridge（中文说明）。这一页讲买什么、怎么接线、App 里怎么设置、指示灯是什么意思；编译和刷固件按仓库里的步骤做。

需要准备

东西说明
Ai-M61-32S-Kit安信可的开发板，芯片是 BL618，带 4 MB PSRAM，几十元。写着 BL616 的是 Ai-M62，没有 PSRAM，不能用。
USB-A 母座转 4 根杜邦母头的线一头是 USB-A 母座，另一头是 4 个分开的 2.54 mm 杜邦母头（卖给电脑主板插针用的那种）。不要买 9 针的，那是给双排插针用的。越短越好。
RTL-SDRRTL-SDR Blog V3、V4，或者其它 RTL2832U 的接收机。
Type-C 线和电源刷固件时接电脑；平时接充电宝或充电头，至少 5V 1A（板子约 500 mA，RTL-SDR 约 250–300 mA）。
天线RTL-SDR 自带的那根就可以开始用。

开发板的 Type-C 口后面已经有一个 USB 转串口芯片，刷固件和看日志都用它，不需要另外买串口工具。

接线

板子正面朝上、天线在上、Type-C 在下放好。一共四根线：左排最下面两个针（5V、GND）和右排从下往上第 5、6 个针（USB_DP、USB_DM），接到 USB-A 母座，RTL-SDR 插在母座上。

板子上的位置（正面，天线朝上）丝印原理图常见线色USB-A 母座
左排倒数第 2 针5VJ1‑20红VBUS
左排最下面 1 针GNDJ1‑21黑GND
右排倒数第 6 针（上面一针是 IO23）USB_DMJ2‑16白D−
右排倒数第 5 针（下面一针是 IO9/NC）USB_DPJ2‑17绿D+

右排最上面那针也是 GND（J2-1），用它代替左排的 GND 也可以。

接线前后要注意：

  • 先断电：拔掉 Type-C，四根线全接好再插回。
  • 5V 和 GND 不能接反，接反可能烧坏 RTL-SDR。插电前再核一遍：左排最下面是 GND，它上面一针是 5V。线的颜色以你手上那根为准；拿不准就用万用表通断档确认母座里哪一针是哪根——母座最外侧两针是 VBUS 和 GND，中间两针是数据线。
  • USB_DM 和 USB_DP 接反不会损坏东西，只是认不出 RTL-SDR，对调就行。
  • 两根数据线跑的是 480 Mbit/s 的 USB 信号，尽量短，两根并在一起走。
  • 板子背面也印着同样的名字，但翻过来看左右两排会对调。以正面为准。

RTL-SDR 的电来自板子的 5V 针，前面串了一个二极管，电压会比 5V 低零点几伏，一般没问题。如果 RTL-SDR 认不出来或者反复断开，先怀疑供电：换一个更强的充电头，或者量一下 5V 针的电压。

刷固件

编译和刷写的完整步骤在 项目的中文说明里，按那里做就行。几个要点：

  • 编译需要一台 x86_64 的 Linux（实体机、虚拟机或云主机都可以）；刷写可以在 Linux 或 Mac 上做。
  • 每次刷写前都要手动让板子进下载模式：按住 IO2 → 按一下 EN 再松开 → 松开 IO2。两个键在 Type-C 口两边，EN 在左，IO2 在右。
  • 刷完按一下 EN，新固件就开始运行。

第一次开机：Wi-Fi 名字和密码

板子开机后会自己开一个热点，名字是 SDR-Bridge- 加四位十六进制数，例如 SDR-Bridge-3F2A。每块板子的密码都不一样：第一次开机时随机生成 12 位，存在板子里，以后每次开机都不变，重新刷固件也不变。

密码只在串口日志里打印。把板子的 Type-C 接到电脑，用 2000000 波特率打开串口，再按一下 EN：

tio -b 2000000 /dev/ttyUSB0                  # Linux
tio -b 2000000 /dev/tty.usbserial-XXXX       # Mac（先 brew install tio）

开机日志里会有这样一行：

[wifi] network "SDR-Bridge-3F2A" up, password xxxxxxxxxxxx

把名字和密码记下来，以后就不用再接电脑了。

为什么不用固定密码：rtl_tcp 本身没有任何认证，连上 Wi-Fi 的人都能改频率、收数据，Wi-Fi 密码是唯一的锁。也可以让板子连手机的个人热点（这样手机还能上网），设置方法见项目说明里的“Wi-Fi 设置”一节。

在 App 里设置

板子的 Wi-Fi 只有大约 30 Mbit/s，所以 App 里有三处要和连电脑时不一样：用 UDP、采样率用 1.024 MSPS、ADS-B 只传幅度。

  1. 手机连上板子的热点

    在 iPhone 的 Wi-Fi 设置里选 SDR-Bridge-XXXX，输入密码。这个热点不能上网，iPhone 会继续用蜂窝数据上网，其它 App 不受影响。

  2. 添加接收机

    按 在 App 里连接 的方法打开接收机编辑页，这样填：

    项目填什么
    TCP / UDP选 UDP
    Hostrtlsdr.local，连不上就填 192.168.7.1
    Port1235

    1234 端口是标准的 TCP 版 rtl_tcp，也能用，但在 Wi-Fi 上 UDP 更快，而且丢了数据 App 能知道丢在哪里。第一次连接时 iOS 会问是否允许 App 访问本地网络，选允许。

  3. 采样率调成 1.024 MSPS

    在 Receiver 页面的设置里，Sample rate 一栏选 1.024 MSPS。这个设置对 Receiver、Radio、ATC 三个页面都有效（要先停止播放才能改）。

    原因：每个采样 2 个字节，1.024 MSPS 是 16.4 Mbit/s，Wi-Fi 很轻松；2.4 MSPS 是 38.4 Mbit/s，已经超过板子的 Wi-Fi 能力，会丢数据，听起来就是断断续续。

  4. ADS-B：打开“只传幅度”

    在 ADS-B 页面的设置里，打开 UDP: magnitude only (half the data)。这个开关只有接收机选了 UDP 时才能打开（默认就是开的）。

    ADS-B 用 2 MSPS 接收，完整的 I/Q 数据是 32 Mbit/s，贴着板子 Wi-Fi 的上限；ADS-B 解码其实只需要信号的强弱，只传幅度数据量减半，就不会丢了。

设置好之后点播放。先去 Radio 页面搜一下 FM 广播，最容易确认一切正常。

指示灯的含义

不接电脑、用充电宝带出去时，靠板子上的灯看它在干什么。板子上有一个 RGB 灯，还有两个单色灯：丝印 W 的黄灯和丝印 C 的白灯。三个灯用同一套语言：

慢闪 = 在等，常亮 = 准备好了，呼吸 = 正在工作，快闪 = 出问题了。

灯回答什么慢闪常亮呼吸快闪
黄灯（W）RTL-SDR 好不好没插 RTL-SDRRTL-SDR 已准备好—插了但打不开，或者 USB 收不到数据
白灯（C）Wi-Fi 和手机到哪一步了Wi-Fi 已开，等手机连上手机已连上，还没开始播放正在传数据—
RGB 灯数据流是否正常—红：Wi-Fi 还没起来蓝：正在传数据，一切正常红蓝：USB 那边丢了数据；紫蓝：Wi-Fi 跟不上，丢了数据
  • 白灯不亮：Wi-Fi 还没起来。
  • RGB 灯在没有播放、也没有出错时是灭的。一次播放自己中断时（比如 RTL-SDR 被拔掉）会红灯常亮 3 秒。
  • 出过一次错，灯会保持那个闪法几秒钟，所以瞄一眼就能看到刚才丢过数据。
  • 拿着板子走动时，哪里开始紫蓝快闪，哪里就是 Wi-Fi 不够了：靠近一点，或者把采样率再调低。

收不好怎么办

现象先查什么
黄灯一直慢闪RTL-SDR 没被认出：检查四根线，尤其是两根数据线有没有错开一位或接反
黄灯快闪，或者 RTL-SDR 反复断开供电不够：换 5V 1A 以上的电源，或者量一下 5V 针的电压
RGB 紫蓝快闪，声音断断续续Wi-Fi 不够：手机靠近板子；关掉手机的蓝牙（蓝牙和 Wi-Fi 抢同一个 2.4 GHz 频段，实测会让速度减半）；杜邦线和手不要贴着板子的天线；采样率不要超过 1.024 MSPS
App 连不上手机是不是连的板子热点；地址换成 192.168.7.1 试试；iOS 设置里有没有允许这个 App 访问本地网络

更多细节，包括让两块板子同时连一台手机、自己检查有没有丢数据，见 项目说明。
