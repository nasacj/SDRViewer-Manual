在 Linux 上安装 rtl_tcp

以 Debian / Ubuntu 为例，其它发行版把 apt 换成自己的包管理器即可。

  1. 安装工具 
    sudo apt update
sudo apt install rtl-sdr

    Fedora 用 sudo dnf install rtl-sdr，Arch 用 sudo pacman -S rtl-sdr。

  2. 屏蔽系统自带的电视棒驱动

    内核会抢先把接收机当成数字电视棒占用，需要把那个驱动屏蔽掉：

    echo 'blacklist dvb_usb_rtl28xxu' | sudo tee /etc/modprobe.d/blacklist-rtl-sdr.conf
sudo modprobe -r dvb_usb_rtl28xxu

    然后把接收机拔下来再插上。（新版的 rtl-sdr 软件包通常已经帮你做了这一步，再做一次也没有坏处。）

  3. 检查能不能认到接收机 
    rtl_test -t

    看到 Found 1 device(s) 和型号就对了。

    如果提示 usb_open error -3，是当前用户没有权限访问 USB 设备。把自己加入 plugdev 组后重新登录：sudo usermod -aG plugdev $USER。

  4. 运行 rtl_tcp 
    rtl_tcp -a 0.0.0.0

    看到 listening... 就是在等手机连接了。-a 0.0.0.0 表示允许其它设备连进来，不能省。

    如果开了防火墙，放行 1234 端口，例如 sudo ufw allow 1234/tcp。

  5. 查到这台电脑的地址 
    hostname -I

    输出的第一个地址（类似 192.168.1.20）就是要填进 App 的。

电脑这边准备好了。接下来：在 App 里连接 →

RTL-SDR Blog V4 / V4L 需要新版驱动

这两个型号需要 librtlsdr 2.0.2 以上（V4L 需要 2.0.3 以上）。用 rtl_test -t 检查：能看到 RTL-SDR Blog V4 Detected 或 RTL-SDR Blog V4 Lite Detected 才算正确识别。如果只显示 R820T 而且收不到任何信号，说明系统自带的版本太旧，需要升级软件包，或者按 RTL-SDR Blog 的说明从源码编译安装。具体命令见树莓派一篇里的这一节：Debian 13（trixie）用方法一；Ubuntu 和其它版本用方法二从源码编译最稳妥。
