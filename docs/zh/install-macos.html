在 macOS 上安装 rtl_tcp

大约五分钟。需要在“终端”里输入三四条命令，照着复制即可。

  1. 安装 Homebrew（已经装过的跳过） Homebrew 是 Mac 上常用的软件安装工具。打开“终端”（在“启动台”里搜索“终端”），粘贴下面这一行并回车，按提示输入开机密码： 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    不确定有没有装过？输入 brew --version，能显示版本号就是装过了。
  2. 安装 RTL-SDR 的工具 
    brew install librtlsdr
    这会装好 rtl_tcp、rtl_test 等几个小程序。
  3. 插上接收机，检查能不能认到 
    rtl_test -t
    看到类似下面的输出就对了（型号不同文字会不一样）： 
    Found 1 device(s):
  0:  RTLSDRBlog, Blog V4L, SN: 00000001
Found Rafael Micro R820T tuner

    如果显示 No supported devices found：换一个 USB 口，或者去掉中间的 USB 集线器再试。

  4. 运行 rtl_tcp 
    rtl_tcp -a 0.0.0.0
    看到 listening... 就是在等手机连接了。这个终端窗口要一直开着，关掉窗口服务就停了；想停止时按 Control + C。

    -a 0.0.0.0 的意思是“允许别的设备连进来”。不加的话只有这台 Mac 自己能连，手机会连不上。

    第一次运行时如果 macOS 弹窗问“是否允许接受传入网络连接”，选允许。
  5. 查到这台 Mac 的地址 另开一个终端窗口，输入： 
    ipconfig getifaddr en0
    会显示一个类似 192.168.1.20 的地址，记下来，下一步要填进 App。（用网线的 Mac 如果没有输出，把 en0 换成 en1 试试；也可以在“系统设置 → 网络”里查看。）

常见问题

RTL-SDR Blog V4 / V4L 没有信号

这两个型号需要较新的驱动。输入 brew upgrade librtlsdr 升级到最新版，再运行 rtl_test -t，应该能看到 RTL-SDR Blog V4 Detected 或 RTL-SDR Blog V4 Lite Detected。

提示 usb_claim_interface error

说明接收机正被另一个程序占用。常见的是已经有一个 rtl_tcp 在运行，或者开着别的 SDR 软件。关掉它们再试。

想让它开机自动运行

最简单的办法是把上面那条命令存成一个脚本，加到“系统设置 → 通用 → 登录项”里。长期使用的话更推荐树莓派，不用一直开着电脑。
