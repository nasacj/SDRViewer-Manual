在 Windows 上安装 rtl_tcp

Windows 需要多一步：先给接收机换一个通用驱动。大约十分钟。

  1. 插上接收机，用 Zadig 安装驱动

    Windows 默认会把它当成电视棒，需要换成 WinUSB 驱动，这一步用一个叫 Zadig 的小工具完成：

    • 从 zadig.akeo.ie 下载 Zadig 并运行。
    • 菜单 Options 里勾选 List All Devices。
    • 下拉列表里选择 Bulk-In, Interface (Interface 0)。有的型号显示为 RTL2838UHIDIR 或 RTL2832U。
    • 右边的驱动选 WinUSB，点 Replace Driver（或 Install Driver），等待一两分钟。

    不要选错设备。如果列表里选成了鼠标、键盘或摄像头，它们会失灵。只对上面写的那一项操作。

  2. 下载 RTL-SDR 工具包

    到 RTL-SDR Blog 的发布页下载最新的 Release.zip，解压到一个容易找到的地方，比如 C:\rtl-sdr。里面的 x64 文件夹中有 rtl_tcp.exe 和 rtl_test.exe。

  3. 检查能不能认到接收机

    在 x64 文件夹的空白处，按住 Shift 点右键，选“在此处打开终端”（或“打开 PowerShell 窗口”），输入：

    .\rtl_test.exe -t

    能看到 Found 1 device(s) 和接收机的型号就对了。如果显示找不到设备，回到第一步重新装一次驱动。

  4. 运行 rtl_tcp 
    .\rtl_tcp.exe -a 0.0.0.0

    看到 listening... 就是在等手机连接了。这个窗口要一直开着。

    防火墙提示一定要点“允许”。第一次运行时 Windows 会弹窗问是否允许访问网络，请勾选“专用网络”并允许。点了取消的话手机会连不上，需要到“Windows 安全中心 → 防火墙 → 允许应用通过防火墙”里把 rtl_tcp 重新勾上。

  5. 查到这台电脑的地址

    再开一个终端窗口，输入：

    ipconfig

    找到正在使用的网络（WLAN 或以太网）下面的 IPv4 地址，类似 192.168.1.20，记下来。

常见问题

换了 USB 口之后认不到了

Windows 的驱动是按 USB 口记的。换了口需要用 Zadig 再装一次，或者插回原来的口。

RTL-SDR Blog V4 / V4L 没有信号

一定要用上面 RTL-SDR Blog 发布页里的工具包，其它来源的旧版本不认识这两个型号。
