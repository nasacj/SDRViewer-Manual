DMR digital voice

DMR (Digital Mobile Radio) is the digital mode of Motorola and Hytera handhelds and of many amateur repeaters; one channel carries two timeslots, so two calls can run at once. SDRViewer receives it exactly as it receives D-STAR and YSF: the same Digital mode, the same card, the same RX History, nothing to choose.

Getting started

  1. Tune to a DMR frequencyEnter the frequency on the Receiver page, such as a local DMR repeater's output.
  2. Choose Digital or NFMEither works: a DMR transmission turns the button to Digital and plays the digital voice; when it ends the button turns back to NFM.
  3. Press play and wait for a transmissionWhen somebody transmits, a card appears at the bottom of the page and the decoded voice plays.

The frequency has to be right. As with the other digital modes, a receiver that is off frequency decodes nothing. Do the frequency calibration first.

What the card shows

WhereMeaning
Top lineWho it is: the name the radio sent over the air (talker alias), otherwise the callsign looked up for its ID, otherwise the 7-digit DMR ID.
→ TG 46001Who is being called. TG is a talkgroup; ID is a private call.
DMR TS2 · ID 4600123 · CC1Timeslot (TS1 or TS2), the caller's DMR ID, and the colour code (CC, the repeater's "house number").
ENCThe call is encrypted. The card and the record still appear, but the voice is not played — encrypted data through a vocoder is only a harsh noise.

A repeater's two timeslots can both be busy; the speaker follows the call that started first and moves to the other when it ends. Each becomes its own record.

Where the callsign comes from

A DMR radio transmits a 7-digit ID, not a callsign. SDRViewer looks for the callsign in this order:

  1. The name the radio sends itself (talker alias). Many radios and BrandMeister repeaters attach the callsign and name to the call. It is the station's own statement, so it comes first.
  2. The RadioID user file you import. Amateur DMR IDs worldwide are registered at RadioID.net. Its terms do not allow the file to be built into the app, so download user.csv with your own RadioID account and import it in Settings. The whole table then lives on the phone and lookups need no network.
  3. Online lookup (on by default). When neither of the above knows an ID, RadioID.net is asked about that one ID and the answer is kept on the phone. This sends the received ID to RadioID.net; turn it off in Settings if you would rather it did not.

A record keeps the ID itself and the callsign is looked up when it is shown, so importing a newer file later names old records too.

DMR records in RX History

They are in the same list as D-STAR and YSF, tagged DMR. The detail page's party section lists the alias (over the air), callsign, name, location, source ID, target, group or private call, timeslot, colour code and the channel kind — repeater output, radio to repeater or direct (radio to radio).

Common situations

What you seeCause and remedy
A signal on the waterfall but no card and no soundThe frequency is off — do the calibration — or it is not DMR.
The card shows a number, not a callsignThe radio sent no alias, no RadioID file is imported, and online lookup is off or has no network.
A card marked ENC and no soundThe call is encrypted and cannot be decoded.
A record that starts mid-sentenceReception started while the station was already talking. DMR repeats who is talking every 360 ms, so a late start still names the caller; it only misses the beginning.
