Install rtl_tcp on Windows

Windows needs one extra step: a generic driver for the receiver. About ten minutes.

  1. Plug in the receiver and install the driver with Zadig

    Windows takes it for a TV tuner by default. It needs the WinUSB driver instead, installed with a small tool called Zadig:

    • Download Zadig from zadig.akeo.ie and run it.
    • In the Options menu, tick List All Devices.
    • In the list choose Bulk-In, Interface (Interface 0). Some models show as RTL2838UHIDIR or RTL2832U.
    • Choose WinUSB as the driver, click Replace Driver (or Install Driver) and wait a minute or two.

    Do not pick the wrong device. Choosing a mouse, keyboard or camera in that list stops it working. Change only the entry named above.

  2. Download the RTL-SDR tools

    From the RTL-SDR Blog releases page, download the latest Release.zip and unzip it somewhere easy to find, such as C:\rtl-sdr. Its x64 folder holds rtl_tcp.exe and rtl_test.exe.

  3. Check the receiver is seen

    In the x64 folder, hold Shift, right-click an empty area and choose "Open in Terminal" (or "Open PowerShell window here"), then:

    .\rtl_test.exe -t

    Found 1 device(s) and the model name mean it is working. If no device is found, go back and install the driver again.

  4. Run rtl_tcp 
    .\rtl_tcp.exe -a 0.0.0.0

    listening... means it is waiting for the phone. Leave the window open.

    Allow it through the firewall. The first time, Windows asks whether to allow network access: tick "Private networks" and allow. If you cancelled, the phone cannot connect; go to Windows Security → Firewall → Allow an app through firewall and tick rtl_tcp.

  5. Find this computer's address

    In another terminal window:

    ipconfig

    Under the network in use (Wi-Fi or Ethernet), note the IPv4 Address, something like 192.168.1.20.

The computer is ready. Next: Connect in the app →

Common questions

It is not seen after moving to another USB port

Windows remembers the driver per USB port. Run Zadig again for the new port, or go back to the old one.

An RTL-SDR Blog V4 or V4L receives nothing

Use the tools from the RTL-SDR Blog releases page above. Older builds from elsewhere do not know these two models.
